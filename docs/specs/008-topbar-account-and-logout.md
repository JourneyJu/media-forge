# 规格：顶部账户区与退出登录

## 背景

登录体系接入后，创作工作台顶部仍保留 `准备就绪` 状态文本和 `新建创作` 按钮。两者在当前阶段容易造成误导：

- `准备就绪` 只是前端状态文案，不代表认证、服务或任务状态。
- 顶部 `新建创作` 与左侧历史栏中的新建入口重复，且像一个假主按钮。
- 登录后缺少清晰的当前账户、角色和退出入口。

## 目标

- 顶部右侧改为账户操作区。
- 去掉顶部 `准备就绪` 状态文本。
- 去掉顶部 `新建创作` 按钮。
- 顶部账户区展示头像和下拉箭头，不占用过多 header 宽度。
- 点击账户区展开账户面板。
- 账户面板展示头像、账号、角色和默认团队。
- 账户面板保留 `账号安全`、`权限范围`、`系统设置` 三个入口，第一阶段可作为占位入口。
- 退出登录放在账户面板底部，使用全宽描边按钮。

## 非目标

- 不在本阶段实现完整个人资料页。
- 不在本阶段实现账号安全页。
- 不在本阶段实现团队切换。
- 不在本阶段实现系统设置真实页面；入口可以先占位或跳转到后续控制台路由。
- 不新增权限模型或 auth API。

## 页面结构

```text
topbar
├─ brand-block
│  ├─ brand-mark
│  └─ brand copy
└─ account-actions
   └─ account-capsule
      ├─ account-menu-trigger
      │  ├─ avatar
      │  └─ chevron
      ├─ account-dropdown
      │  ├─ profile summary
      │  ├─ 账号安全
      │  ├─ 权限范围
      │  ├─ 系统设置
      │  └─ 退出登录
```

## 视觉规则

- 顶部栏继续使用当前浅色、低密度 SaaS 工作台风格。
- 品牌区保持现状：橙色圆角 `M` 标识、`MediaForge` 和 `公众号创作平台`。
- 账户胶囊右对齐，替代原顶部状态区。
- 胶囊背景使用白色或半透明白，边框沿用当前 `#D8E5DE` 附近的浅色边线。
- 头像使用与 Logo 同源的 coral / amber 渐变，显示单字 `管`。
- Header 中只展示头像和 chevron，避免挤占顶部宽度。
- 下拉面板使用白底、8px 圆角、轻阴影，不使用深色面板。
- 下拉面板顶部展示 `admin`、`Owner` 和 `默认团队`。
- 退出按钮使用 coral 描边和文字，位于面板底部。

## 交互规则

### 账户胶囊

- 点击头像区域或 chevron 展开账户下拉。
- 再次点击或点击外部区域关闭下拉。
- 下拉第一阶段展示 `账号安全`、`权限范围`、`系统设置`。
- 这三个入口可以先作为禁用态、占位路由或跳转到后续控制台路由；实现时必须避免 404 裸跳。

### 退出登录

- 退出按钮放在下拉面板底部。
- 点击后调用 `POST /auth/logout`。
- 成功后清理本地登录态，并跳转到 `/login`。
- 失败时保留当前页面，并给出可理解错误提示。

### 新建创作

- 顶部不再展示 `新建创作`。
- 新建创作入口保留在左侧历史栏顶部 `＋` 按钮。
- 新建创作仍只清空前端本地状态，不创建后端 Conversation。

## 响应式规则

- 桌面端 header 只展示头像和 chevron，账户信息在下拉面板内展示。
- 窄屏时下拉面板宽度不得超过视口宽度。
- 极窄屏时仍必须保留退出按钮的可访问名称。

## 可访问性

- 账户菜单触发器使用 `aria-haspopup="menu"` 和 `aria-expanded`。
- 下拉使用 `role="menu"`，`系统设置` 使用 `role="menuitem"`。
- 退出按钮文本为 `退出登录`，不能只使用图标。
- 键盘用户可以通过 Tab 聚焦账户菜单和退出按钮。

## 验收标准

- 顶部不再出现 `准备就绪`。
- 顶部不再出现 `新建创作`。
- 顶部右侧展示头像和 chevron。
- 点击账户区域出现账户面板，包含 `admin`、`Owner`、`默认团队`、`账号安全`、`权限范围`、`系统设置` 和 `退出登录`。
- `退出登录` 是面板底部全宽描边按钮。
- 点击退出后调用 auth logout，并回到登录页。
- 未登录访问创作页仍由路由守卫跳转到 `/login`。
