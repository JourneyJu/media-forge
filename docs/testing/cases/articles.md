## 用例

| ID | 场景 | 步骤 | 预期 |
| --- | --- | --- | --- |
| ART-001 | 创建文章草稿 | 在 Conversation 内创建文章 | 返回带 `conversationId` 的 `draft` 文章摘要。 |
| ART-002 | 保存 AI 版本 | 提交合法 `ArticleDocument` | 写入 `article_versions.content_json` 和 `html_snapshot_key`。 |
| ART-003 | 拒绝非法结构 | 提交缺少 `type=doc` 的内容 | 返回 `ARTICLE_SCHEMA_INVALID`，不创建版本。 |
| ART-004 | 渲染微信 HTML fragment | 对当前版本执行 render | HTML 不包含完整文档包装、脚本、事件属性和外部 CSS。 |
| ART-005 | 记录富文本复制事件 | 成功把当前版本写入剪贴板 | 写入 `copy_wechat_html` 导出事件，文章可转为 `exported`。 |
| ART-006 | 恢复历史版本 | 从 `version_1` 恢复 | 创建新版本，不直接回指历史版本。 |
| ART-007 | 视频 warning | 文章含 `video` 块 | 渲染结果包含 `video_fallback` warning。 |
| ART-008 | Conversation 级删除 | 删除文章所属 Conversation | Article、全部 Version、导出事件和对象快照最终不存在。 |
| ART-009 | 禁止文章独立硬删除 | 尝试调用文章 DELETE | 接口不存在或拒绝，提示通过 Conversation 删除。 |
| ART-010 | 双 MIME 剪贴板 | 在支持 `ClipboardItem` 的浏览器点击“复制到公众号” | 一次写入同时包含 `text/html` 和 `text/plain`，两者语义和内容顺序一致。 |
| ART-011 | Markdown 不泄漏到富文本 | 文章含粗体标题和粗体日程项 | HTML 使用语义标签或内联样式，粘贴结果不显示 `**`。 |
| ART-012 | 纯文本可读性 | 对含标题、列表和多段正文的文章生成 `text/plain` | 保留合理换行和顺序，不包含 HTML 标签或 Markdown 样式标记。 |
| ART-013 | 不支持富文本剪贴板 | 浏览器没有 `ClipboardItem` 或富文本写入能力 | 不显示完整复制成功，提示并提供纯文本复制入口。 |
| ART-014 | 剪贴板权限被拒绝 | 拒绝页面剪贴板权限后点击复制 | 显示可恢复的失败提示，不记录成功导出事件。 |
| ART-015 | 剪贴板写入异常 | 模拟 `navigator.clipboard.write` reject | 页面内容保持不变，不记录成功事件，可重试或复制纯文本。 |
| ART-016 | 纯文本降级事件 | 用户确认并成功复制纯文本 | 使用独立导出类型记录，不计为 `copy_wechat_html`。 |
| ART-017 | HTTPS 图片 | 文章含多张 HTTPS 公网图片 | fragment 保留图片顺序，图片使用块级自适应内联样式。 |
| ART-018 | 不兼容图片 URL | 图片使用 HTTP、本地路径、`blob:`、`data:` 或缺少 URL | 返回对应 warning，界面标明受影响图片，不承诺完整带图复制。 |
| ART-019 | 复制结果统计 | 当前版本含多个段落和图片 | 复制前后展示的段落数、图片数与 `ArticleDocument` 一致。 |
| ART-020 | 真实公众号粘贴 | 在 Chrome/Edge 复制包含居中、粗体、日程和 HTTPS 图片的文章并粘贴到公众号正文 | 无 Markdown 标记；文字层级、顺序和基础样式可用；图片顺序一致，平台清洗差异有记录。 |
| ART-021 | 平台字段边界 | 富文本复制成功后检查提示和公众号表单 | 明确提示标题、作者、摘要、封面需单独设置，正文剪贴板不声称已填写这些字段。 |
| ART-022 | 最小布局变更 | 打开已有对话创作工作台并与改动前基线对比 | 三栏结构、各栏宽度、对话区、底部输入区和手机预览尺寸不变。 |
| ART-023 | 复制按钮文案 | 查看右侧手机预览栏顶部 | 原“复制 HTML”按钮显示为“复制到公众号”，位置、尺寸和样式保持一致。 |
| ART-024 | 预览状态条统计 | 当前版本含 12 个段落、4 张图片和 2 个 warning | 手机预览下方显示“12 段 · 4 图”和“2 项需处理 >”，renderer 版本作为弱化信息保留。 |
| ART-025 | 无问题状态 | 当前版本没有兼容性 warning | 状态条保留段落和图片统计，右侧显示“可复制”。 |
| ART-026 | 查看兼容性问题 | 点击状态条“2 项需处理 >” | 复用现有 warning 展示能力并显示对应问题，不打开新增常驻发布面板。 |
| ART-027 | 复制中防重复 | 点击“复制到公众号”并让剪贴板写入保持 pending | 按钮显示加载状态且不可重复触发复制和导出事件。 |
| ART-028 | 富文本复制成功 Toast | 富文本剪贴板写入和导出事件记录成功 | 右侧栏底部显示“正文已复制”和“标题、摘要和封面需单独设置”，不遮挡预览或按钮并自动消失。 |
| ART-029 | 复制失败不误报 | 模拟剪贴板写入失败 | 不显示“正文已复制”Toast，展示可恢复错误并允许重试或纯文本降级。 |
| ART-030 | 版本更新刷新统计 | 从一个文章版本切换到段落数、图片数或 warning 数不同的版本 | 状态条使用新版本统计，不残留旧版本数据。 |
