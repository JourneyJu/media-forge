# 安全规范

## 密钥

- 不把 API Key、token、数据库密码写入代码。
- `.env` 不提交仓库。
- 模型 API Key 必须加密保存。
- 登录、改密等密码提交请求不得在 JSON body 中传输明文密码；前端必须先使用 auth 服务发布的 RSA-OAEP 公钥加密。
- 日志不得输出完整密钥、prompt 中的敏感配置或用户隐私。
- 日志脱敏遵循 `docs/standards/logging.md`。

## 数据隔离

- 所有用户数据查询必须带租户或工作区上下文。
- 前端不得直接访问数据库、对象存储或模型供应商。
- 对象存储 key 不允许依赖用户可猜测路径做权限控制。
- 后端查询不能只按资源 id 返回数据，必须同时校验用户、租户或工作区归属。

## 文件上传

- 限制文件类型和大小。
- 保存原图前后都要记录元数据。
- 图片识别失败不能影响用户删除素材。
- 可疑图片需要标记状态，不静默通过。

## AI 安全

- 内容生成需要检查禁用词、高风险表达和明显违规内容。
- prompt 快照可以保存，但不能包含明文密钥。
- 长期记忆必须允许关闭、清空和纠错。
